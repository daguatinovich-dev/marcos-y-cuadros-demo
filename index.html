function doPost(e) {
  const sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  const data = JSON.parse(e.postData.contents);
  sheet.appendRow([new Date(), data.id, data.cliente, data.contacto, data.diseno, data.cantidad, data.pago, data.total]);
  return ContentService.createTextOutput(JSON.stringify({ status: "ok" })).setMimeType(ContentService.MimeType.JSON);

Vista Detallada

Arquitectura del Proyecto — GitHub Portfolio

Esta aplicación fue diseñada como una solución zero-dependency lista para desplegar en GitHub Pages sin backend costoso, resolviendo necesidades reales de catálogo, personalización y registro contable para un emprendimiento local.

Frontend & 3D UI HTML5 semántico, CSS Grid/Flexbox, Transformaciones 3D interactivas con reflejo especular y microinteracciones táctiles.
Motor de Personalización API FileReader con validación de cabecera binaria (Magic Bytes) y doble plantilla (Póster / Spotify).
Persistencia & Excel Estado persistente en localStorage + generador .CSV con BOM UTF-8 compatible con Excel y webhook Google Apps Script.
Seguridad & QA Escapado estricto anti-XSS, política CSP, marco legal Ley 25.326 / 24.240 y autodiagnóstico de errores en cliente.
